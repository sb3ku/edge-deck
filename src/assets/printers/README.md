# Printer images

Edge Deck shows a photo of each printer on the printer card. The images are not part of this repository, because they belong to their makers (Bambu Lab's product photos and Bambu Studio's artwork).

To use photos, add transparent PNG files here:

| File | Printer |
| --- | --- |
| `h2d-photo.png` | Bambu Lab H2D |
| `p1s-photo.png` | Bambu Lab P1S |

Without them the card shows a plain printer icon. While a print runs, the card shows the printer's own preview of the model instead.
